# XHS-SCoRE — Pre-EMNLP 2026 Main Conference Release

**Version:** v0.9.0

This pre-conference release presents XHS-SCoRE as a publication-facing research repository following acceptance to the EMNLP 2026 Main Conference.

## Included in v0.9.0

- a concise publication homepage in `README.md`;
- a comprehensive interactive paper companion in `PAPER.md`;
- a compact `AGENTS.md` entry point for AI and coding agents;
- a curated English reconstruction of the original collector instructions;
- arXiv-only citation metadata in ACL, APA, BibTeX, and CFF formats;
- links for GitHub Raw and jsDelivr-based interactive reading;
- the existing policy-compliant generated data, scripts/configurations, predictions, and study materials.

## Citation status

This release uses the arXiv record (`2605.01017`) as the citation source. Proceedings metadata will be added after the formal EMNLP publication record is available.
